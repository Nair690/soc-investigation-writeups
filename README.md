# SOC Investigation Write-ups

Hi, I'm Sharath. I'm transitioning into cybersecurity (SOC Analyst / Security 
Operations) after 6+ years as an analyst in sports at Hudl, 
where I worked extensively with large datasets, structured workflows, and 
cross-team coordination.

This repository is a collection of incident investigation write-ups from my 
hands-on security training — including practice scenarios from LetsDefend 
and TryHackMe, and concepts I've studied through CompTIA Security+ and 
Network+ coursework.

Each write-up follows a consistent format:
- **Summary** — what happened, in plain language
- **Timeline** — the sequence of events with timestamps
- **Analysis** — reasoning, mapped to MITRE ATT&CK techniques where relevant
- **Recommendation** — the containment/escalation action taken

## Why this repo exists

I believe in showing the actual thinking process behind an investigation, 
not just completing training modules. These write-ups reflect how I'd 
approach real alert triage as a SOC analyst — reading logs, identifying 
patterns, and documenting findings clearly for escalation.
